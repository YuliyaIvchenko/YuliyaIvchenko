# О себе
Привет, я Ивченко Юлия - начинающий аналитик данных с фокусом на продуктовой и бизнес‑аналитике.

## Ключевые задачи и достижения:
-построение и анализ воронок конверсии для выявления узких мест и точек роста;
-расчёт retention, LTV и других продуктовых метрик (MAU, DAU, CR) для оценки здоровья продукта;
-поиск аномалий в данных и причин их возникновения, анализ отклонений ключевых показателей;
-формулировка и проверка гипотез через A/B‑тесты и когортный анализ с оценкой статистической значимости результатов;
-подготовка аналитических отчётов и дашбордов с визуализацией данных для стейкхолдеров;
-оптимизация бизнес‑процессов и продуктовых решений на основе данных — с фокусом на рост конверсии и удержание пользователей.

## Технический стек и навыки:
-SQL (ClickHouse, оконные функции, CTE) — для извлечения и трансформации данных;
-Python (pandas) — для предобработки, анализа и автоматизации рутинных задач;
-Spark — для работы с большими данными и масштабируемых вычислений;
-Airflow (основы) — для оркестрации ETL‑пайплайнов и автоматизации процессов;
-Основы визуализации (BI‑инструменты, понимание принципов построения дашбордов);
-понимание продуктовых фреймворков (AARRR) и юнит‑экономики для комплексной оценки бизнес‑эффекта.

## Цель:
Ищу позицию начинающего аналитика данных в продуктовой команде, чтобы применить навыки анализа воронок, A/B‑тестирования и построения дашбордов для роста ключевых метрик продукта. Готова участвовать в построении аналитической инфраструктуры и помогать бизнесу принимать решения на основе данных.
